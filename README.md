Простой Telegram бот, интегрированный с языковой моделью (LLM) через API. Бот поддерживает историю диалога.
Команды управления:

/start - приветствие и список команд

/model - показывает используемую языковую модель

/clear - очищает историю диалога

любой текст для ответа бота с помощью LLM

Инструкция по запуску:
Для запуска необходимо предварительно установить LM Studio и загрузить с платформы Hugging Face языковую модель. Также нужно предварительно создать Telegram бота и подключить к проекту . 
Напишите @BotFather в Telegram (Команда: /newbot) и получите токен.
Установите зависимости:

pip install pyTelegramBotAPI requests jsons

Запустите бота:

python main.py
