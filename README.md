Telegram LLM Bot

Простой Telegram бот, интегрированный с языковой моделью (LLM) через API. Бот поддерживает историю диалога.

Команды управления:

/start - приветствие и список команд

/model - показывает используемую языковую модель

/clear - очищает историю диалога

любой текст для ответа бота с помощью LLM

Инструкция по запуску:

Создайте бота: Напишите @BotFather в Telegram

Команда: /newbot

Получите токен

Установите зависимости:

pip install pyTelegramBotAPI requests jsons

Запустите бота:

python main.py
